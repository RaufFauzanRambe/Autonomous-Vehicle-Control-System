# IMPORTANT — aarch64 / L4T specific notes:
#   * `torch` and `torchvision` are NOT installed from PyPI on Jetson.
#     Use NVIDIA's pre-built wheels for JetPack 5.x:
#       pip3 install \
#         https://nvidia.box.com/shared/static/.../torch-2.0.0-cp310-cp310-linux_aarch64.whl
#     The Dockerfile in this directory handles that automatically.
#   * `tensorrt` Python bindings ship with JetPack and live in
#       /usr/lib/python3.10/dist-packages/tensorrt/
#     Add that path to PYTHONPATH if pip doesn't find them.
#   * `opencv-python-headless` is preferred over `opencv-python` on headless
#     Jetson deployments (no GUI/X11).
# ----------------------------------------------------------------------------
